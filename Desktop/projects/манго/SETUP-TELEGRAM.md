# Підключення бронювання до Telegram (15–20 хвилин, безкоштовно)

Схема: сайт → Cloudflare Worker (`worker.js`) → бот у Telegram → повідомлення власнику.
Токен бота зберігається тільки у Worker, у файлах сайту його немає.

## 1. Створіть бота
1. У Telegram відкрийте **@BotFather** → `/newbot` → вкажіть назву та ім'я (закінчується на `bot`).
2. Збережіть **токен** (довгий рядок виду `123456:ABC...`). Нікому його не показуйте.

## 2. Дізнайтесь chat_id
1. Той, хто має отримувати заявки (власник/адмін), відкриває бота й натискає **Start**.
   Для групи: додайте бота в групу й напишіть там повідомлення.
2. У браузері відкрийте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Знайдіть `"chat":{"id":...}` — це число і є **chat_id** (для груп воно від'ємне).

## 3. Створіть Worker на Cloudflare
1. Зареєструйтесь на cloudflare.com → **Workers & Pages** → **Create** → **Create Worker** → **Deploy**.
2. **Edit code** → видаліть усе й вставте вміст `worker.js` → **Deploy**.
3. **Settings → Variables and Secrets** додайте:
   - `BOT_TOKEN` (тип Secret) — токен із кроку 1
   - `CHAT_ID` (Secret) — число з кроку 2
   - `ALLOWED_ORIGIN` (Text) — адреса сайту, напр. `https://mango-bbq.example.com` (кілька адрес через кому)
4. Скопіюйте адресу Worker (`https://....workers.dev`).

## 4. З'єднайте з сайтом
Відкрийте `booking.js` і вставте адресу в першому рядку налаштувань:
`const BOOKING_ENDPOINT = 'https://....workers.dev';`

## 5. Розмістіть сайт і перевірте
Форма не працює, якщо відкривати файл подвійним кліком (`file://`), потрібен справжній хостинг: Cloudflare Pages, Netlify або GitHub Pages (усі безкоштовні). Завантажте `index.html`, `style.css`, `booking.js` і папку `images`.
Надішліть тестову заявку: повідомлення має прийти в Telegram.

Якщо не приходить: перевірте, що власник натиснув Start у бота, що `ALLOWED_ORIGIN` точно збігається з адресою сайту (з `https://`, без `/` в кінці), та що Worker заново розгорнуто після змін змінних.
